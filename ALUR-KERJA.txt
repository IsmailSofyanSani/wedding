  FLOW DIAGRAM: URL PARAMETER SYSTEM
═══════════════════════════════════════════════════════════════════════════

  INPUT                        PROCESS                      OUTPUT
  ─────                        ───────                      ──────

  "Bapak Ahmad"         →     encodeURIComponent()    →    "Bapak%20Ahmad"
                              (di generator)

                              ↓

  URL Created:          →     index.html?to=Bapak%20Ahmad
                              
                              ↓

  Browser Parse         →     URLSearchParams.get('to')
                              
                              ↓

  Decode                →     decodeURIComponent()    →    "Bapak Ahmad"
                              (di index.html)

                              ↓

  Display               →     document.getElementById()
                              
                              ↓

  Result                →     "Kepada Yth. Bapak Ahmad"
                              (muncul di undangan)
