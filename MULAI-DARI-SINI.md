# 🎉 SELAMAT DATANG!

## Sistem Undangan Pernikahan Digital dengan Auto-Fill Nama Tamu

Website undangan pernikahan yang elegant dengan fitur **otomatis mengisi nama tamu** berdasarkan link yang dikirim.

---

## ⚡ QUICK START (3 Langkah)

### 1. 📝 Tambah Tamu
Buka file **`daftar-tamu.js`** → Tambahkan nama tamu

### 2. 🔗 Generate Link  
Buka **`generator-link.html`** di browser → Generate link

### 3. 📱 Kirim!
Copy link → Kirim via WhatsApp/Email/SMS

✅ **SELESAI!** Tamu akan melihat nama mereka di undangan.
